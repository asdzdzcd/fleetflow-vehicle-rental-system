# fleetflow-vehicle-rental-system

Cloud-Based Vehicle Rental Management System built with React, FastAPI, PostgreSQL, and AWS.

## Features

- JWT Authentication
- Vehicle Booking
- Fleet Management
- Admin Dashboard
- Revenue Analytics
- ETL Pipeline

## Tech Stack

| Layer | Technology |
|--------|------------|
| Frontend | React + Vite |
| Backend | FastAPI |
| Database | PostgreSQL |
| Cloud | AWS |
| Version Control | Git & GitHub |

Currently under development.
